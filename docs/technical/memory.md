# 记忆功能实现说明

AIbox Mobile 的记忆功能参考 Chatbox 1.23.4 的核心方案实现：保存少量可控的文本记忆，在每次请求生成 prompt 前作为独立的 system 上下文注入。

## 当前能力

- 全局文本记忆：最多 100 条，每条最多 1000 个字符。
- 记忆内容会去除首尾空白并按完整内容去重。
- 设置页可以启用/停用、添加、删除和清空记忆。
- 记忆上下文最多注入 8000 个字符；当前用户消息优先于历史记忆。
- 记忆存储使用现有 `StoreStorage` 抽象：Android 使用既有 SQLite `key_value` 表，Web/Electron 使用既有平台存储，不新增数据库迁移。
- 记忆存储读取失败时，聊天会继续执行但不注入记忆。

## 暂未实现

- 自动从对话中提取事实。
- 向量 embedding、语义检索和项目级记忆。
- `save_memory` 模型工具。

这些能力可以在第一版稳定后单独增加，避免自动提取或检索故障影响主聊天链路。
